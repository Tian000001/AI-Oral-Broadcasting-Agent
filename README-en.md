## Overview

TTQ-Video is an automated short-video generator built on top of the open-source
[MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) project.

Give it a topic or a script and it runs the whole flow:
**script writing → voiceover → subtitles → material matching → video assembly**.
On top of that, this fork adds a "talking-head agent" and a visual
**koubo video workbench (TalkStudio)** for scene-based scripts, digital humans,
voice cloning, and one-click export.

> This project has diverged from upstream and evolves independently. It performs
> no upstream version check and no auto-update.

## Features

### 1. One-click AI short video
- **Script & search terms** generated by an LLM: MoonShot (default), OpenAI,
  DeepSeek, Qwen, Azure OpenAI, SiliconFlow, local Ollama, OneAPI, and more
  (presets in `app/models/llm_provider.py`).
- **Multi-engine voiceover**: Edge TTS (default, no API key), Azure Speech,
  SiliconFlow, MiniMax, ElevenLabs, Chatterbox, Gemini, plus local XTTS /
  CosyVoice voice cloning.
- **Automatic subtitles** via Whisper (large-v3 by default, CPU int8 works;
  downloaded to `models/` when missing).
- **Materials** from Pexels / Pixabay / Coverr or local images / videos;
  optional TwelveLabs semantic re-ranking.
- **Final cut** assembled with MoviePy; optional BGM (Sonilo / local songs),
  transitions, and video effects.

### 2. Talking-head agent (口播智能体)
- **Scheduling dashboard**: priority queue, retries, manual review, cancellation.
  Task state lives in Redis, and interrupted tasks are reconciled on restart.
- **Personas & compliance**: persona management, compliance review, reference
  material fetching (yt-dlp), title and cover generation.
- **Vendor capability registry**: one vendor with many models, with online fetch
  of model / voice lists.

### 3. Koubo video workbench (TalkStudio)
- **Data-driven scene timeline**: each node is a `scenes[]` JSON entry — edit the
  JSON to edit the video.
- **Live preview** built on Remotion `<Player>`; preview and export share the same
  render, so what you see is what you get.
- **Per-scene fine control**: text style (color / size / layout), picture-in-picture,
  voiceover overlay mode, and **per-scene video insertion**, all overridable per node.
- **One-click export**: a full MP4 cut, or a transparent overlay MOV
  (ProRes 4444 + Alpha) for further compositing in CapCut.
- **Asset archiving**: exported videos can be stored straight into the built-in
  asset library for reuse.

### 4. Tech video / auto video
- Copy-driven dynamic video (Remotion) with chart, timeline, and comparison
  scene templates.
- Cross-cut / background-talking-head / picture-in-picture overlay modes.

### 5. Three ways to use it
- **WebUI**: open <http://127.0.0.1:8080/>
- **REST API**: interactive docs at <http://127.0.0.1:8080/docs> (everything under `/api/v1`)
- **Command-line CLI**: see below

## Requirements

| Component | Notes |
| --- | --- |
| OS | Windows 10/11 (the one-click launcher is a `.bat`; other platforms can start the backend manually) |
| Python | 3.11 — the Windows distribution bundles `python/` (3.11.15), no separate install needed |
| ffmpeg | Bundled at `ffmpeg/ffmpeg-7.0-essentials_build`; on non-Windows, install it yourself and add it to PATH |
| Redis | Used for task state and queues; connects to localhost by default (point it elsewhere with `MPT_APP_REDIS_HOST` / `REDIS_HOST`) |
| Node.js | Required for offline rendering and frontend builds of the koubo / tech-video pages (Node 18+ recommended) |
| API keys | Configure LLM and material-platform keys as needed — see Configuration |

> **Not shipped with the source**: `python/`, `ffmpeg/`, and `models/` are large,
> and `resource/fonts/` (proprietary `.ttc` fonts such as Microsoft YaHei /
> STHeiti) plus `resource/songs/` (bundled BGM) also carry third-party copyright.
> All of these are excluded via `.gitignore` — use the official release package, or
> provide the runtime, models, and fonts yourself.
> The default subtitle font is `STHeitiMedium.ttc`; if you do not ship it, replace
> it with a font you are licensed to use (see `[ui]` / subtitle settings in
> `config.toml`).

## Quick start

1. Copy the config template and fill in the keys you need:

   ```bat
   copy config.example.toml config.toml
   ```

   > `config.toml` holds secrets and is ignored by `.gitignore` — **never commit it**.

2. Double-click `start_app.bat`. The script automatically: frees port 8080 →
   starts the backend in a new window (live logs) → waits for readiness and
   self-checks → opens your browser.

3. Or start the backend manually:

   ```bash
   python\python.exe main.py
   ```

   Then open <http://127.0.0.1:8080/>. If the browser cannot load it, try
   <http://localhost:8080/> and disable any proxy for localhost.

## Frontend build (koubo / tech video)

The browser pages are bundled from `techvideo/` with esbuild. The repository ships
with prebuilt bundles, so it works out of the box; **after editing
`techvideo/src`, rebuild**:

```bash
cd techvideo
npm install
npm run web:build     # same as: node build.mjs
```

Output goes to `resource/public/koubo/` (koubo workbench) and
`resource/public/techvideo/` (tech video), which are independent of each other.
Offline rendering (MP4 export) also relies on `techvideo/node_modules`, so make
sure `npm install` has been run.

## Command line (CLI)

```bat
:: Generate a complete video from a topic (default Edge TTS, no API key)
python\python.exe -m app.cli --video-subject "How AI is changing everyday life"

:: Local materials + a prepared script, no voiceover, straight to the final cut
python\python.exe -m app.cli --video-script "Your complete script" ^
  --video-source local --video-materials "./1.mp4,./2.mp4" ^
  --voice-name no-voice --stop-at video

:: Stop after the script stage (pipeline: script → terms → audio → subtitle → materials → video)
python\python.exe -m app.cli --video-subject "topic" --stop-at script
```

See all options: `python\python.exe -m app.cli --help`

## API overview

All routes share the `/api/v1` prefix; `/docs` exposes the full interactive
documentation once the server is running:

| Module | Paths | Purpose |
| --- | --- | --- |
| Video tasks | `/api/v1/videos`, `/api/v1/tasks`, `/api/v1/stream`, `/api/v1/download` | Submit tasks, query / delete, stream and download results |
| Talking-head agent | `/api/v1/agent/*` | Dashboard, personas, compliance, reference materials, title / cover, TTS preview, vendor registry |
| Tech video / workbench | `/api/v1/techvideo/*` | Material upload, script generation, offline render, gallery, asset archiving |
| Stock search | `/api/v1/stock/*` | Keyword extraction, Pexels image / video search |
| Asset library | `/api/v1/agent/assets` | Upload, list, and delete image / audio / video assets |
| Others | `/api/v1/llm/*`, `/api/v1/fonts`, `/api/v1/system` | LLM chat, font list, system config |

Static mounts: `/` (WebUI), `/tasks` (task artifacts), `/koubo/` (koubo workbench),
`/techvideo/` (tech video), `/techvideo-public` (uploads), `/techvideo-media` and
`/techvideo-videos` (audio tracks and rendered videos).

## Configuration

Copy `config.example.toml` to `config.toml` (basic settings can also be edited in
the WebUI). Main sections:

| Section | Contents |
| --- | --- |
| `[app]` | General settings, material providers and their API keys, LLM provider, redis_host, listen address / port |
| `[whisper]` | Subtitle model (model_size / device / compute_type) |
| `[proxy]` | Proxy for material requests |
| `[azure]` `[siliconflow]` `[minimax_tts]` `[elevenlabs]` `[chatterbox]` | Keys and parameters of the TTS services |
| `[agent]` `[persona]` `[digital_human]` `[voice_clone.*]` `[compliance]` `[publishing]` `[reference]` `[title_cover]` | Talking-head agent settings (persona, digital human, voice cloning, compliance, publishing) |
| `[ui]` | UI customization |

## Versioning

The single source of truth for the version is `__version__` in
`app/__init__.py`, using a decimal `major.minor.patch` scheme. After every change,
bump it with `bump_version()` (carry at 9, e.g. `1.9.9 → 2.0.0`).

## FAQ

- **Browser cannot load / blank page**: first check the backend window
  (`MPT-Backend`) for errors; then try <http://localhost:8080/> and disable any
  proxy for localhost.
- **Frontend changes not taking effect**: the static assets are build outputs —
  rebuild with `npm run web:build` inside `techvideo/`, then hard-refresh the
  browser (`Ctrl/Cmd + Shift + R`).
- **Backend changes not taking effect**: `reload_debug=False` by default, so there
  is no hot reload — restart the backend.
- **Export fails with "node not found"**: install Node.js and make sure `node` is
  on PATH, or set `techvideo_node_path` under `[app]` in `config.toml`.
- **`WinError 10054` spamming the console**: a client disconnect (browser
  cancelling / refreshing a large download). It is benign noise and is now
  silenced in `main.py`.
