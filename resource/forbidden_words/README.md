# 违禁词 / 敏感词库（口播智能体 · Phase 6）

本目录按**行业**存放违禁词 / 敏感词，供 `app/services/agent/compliance.py` 加载检测。
文件名即行业名（如 `finance.txt` → 金融行业），新增行业只需新增同名 `.txt` 即可，无需改代码。

## 每行格式

    模式                    # 纯文本，按 default_level 定级（默认 warn）
    模式|block              # 指定级别：block（应阻断）/ warn（仅提示建议改写）
    模式|warn|建议改写说明
    模式|block|建议改写|变体1,变体2   # 变体（同音 / 形近）一并匹配
    /正则表达式/|block|说明           # 以 / 包裹表示正则
    # 这是注释

- **级别语义**
  - `block`：硬性违规，应阻断发布（毒品、赌博、色情、政治敏感、根治/包治等绝对化医疗承诺等）。
  - `warn`：高风险措辞，可能限流或触发审核，给出改写建议但不阻断（「最」「第一」「美白」等）。
  - 是否真正阻断由 `config.compliance.block_on_hit` 控制；关闭时即使命中 block 词也只上报。
- **变体**：同一触发词的同音 / 形近写法（如 `旺旺|block|...|王旺,汪汪`），全部参与匹配，防变体规避。
- **正则**：`/.../` 包裹，可覆盖复杂变体（如 `/旺旺|王旺|汪汪/`）。

## 维护建议

- 词库需持续维护：各平台社区规范会更新，定期对照抖音 / 视频号 / 小红书等规则增补。
- 误报处理：把易误报的常规词改为 `warn` 或加更具体的上下文词；或对整体关闭 `block_on_hit` 使其仅作提示。
- 用户自定义词放在 `storage/forbidden_words/custom.txt`（同格式），也可通过 API 增删，热更新无需重启。
- 当前覆盖 34 个行业。
